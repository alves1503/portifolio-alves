# Projetos

## Alves.CRM — Atendimento inteligente com IA
Aplicação web de CRM para gerenciar atendimentos, conversas via WhatsApp, leads e reuniões. Possui autenticação e integração com a Evolution API. O agente baseado em GPT-4o mini responde dúvidas sobre serviços, qualifica leads e auxilia no agendamento de reuniões; quando não há informação suficiente, encaminha o atendimento para uma pessoa. Usa RAG com embeddings e uma base de conhecimento gerenciada pelo CRM, que permite cadastrar serviços e atualizar informações utilizadas pela IA. Leads e reuniões também podem ser gerenciados manualmente. Redis mantém o contexto das conversas. Tecnologias: Java, Spring Boot, React, MySQL, Redis, OpenAI API, Evolution API, RAG, embeddings e Docker. Repositório: https://github.com/alves1503/crm-alves.

## Agente de IA para WhatsApp — Qwen e n8n (experimental)
Projeto experimental para testar agentes de IA em um fluxo de atendimento via WhatsApp. Usa Qwen 3.6 Plus via Alibaba Cloud Model Studio, n8n para orquestrar ferramentas, Evolution API para comunicação, MySQL para consulta de produtos, RAG simples e Docker. O agente pode consultar dados e responder perguntas sobre produtos. O projeto também explora testes de segurança com prompt injection e instruções maliciosas. É um laboratório de aprendizado, não deve ser usado diretamente em produção sem melhorias de segurança, autenticação, tratamento de erros, gestão de credenciais, observabilidade e arquitetura. Repositório: https://lnkd.in/dXSfc4Qy.

## Chatbot inteligente para atendimento
Aplicação full-stack de atendimento automatizado com chat em tempo real, integração com Gemini API, catálogo de produtos em banco de dados e documentação Swagger. Tecnologias listadas: PHP, React, MySQL, Vite, Swagger, Gemini API e Docker. Repositório: github.com/alves1503/chat-product-php.

## Plataforma de gestão de denúncias
Projeto acadêmico em ASP.NET Core MVC para registro, acompanhamento e gestão de denúncias, com autenticação, controle por perfil e persistência em SQL Server via Entity Framework. Repositório: github.com/alves1503/sistema-denuncias.

## Conexão Editores
Plataforma front-end para conectar clientes e editores de vídeo, com páginas institucionais, cadastro e login. Repositório: github.com/alves1503/conexao-editores.

## Account — Simulador financeiro
Aplicação de terminal em Node.js para simular criação de conta, depósitos, saques e consultas de saldo, com armazenamento local em JSON. Repositório: github.com/alves1503/account.
